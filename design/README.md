# Концепт визуального языка

`modcase-concept.html` — самодостаточная интерактивная страница: открывается в
браузере без сборки. Это не макет, а работающий прототип визуального языка,
на который опирается тема приложения.

## Идея

Мир 3D-печати вместо абстрактного «неон-техно»: рабочий стол слайсера, стол
принтера, слои, расплав. Курсор — сопло, оставляющее остывающий экструзионный
след.

## Токены

| Токен | Значение | Роль |
| --- | --- | --- |
| `--plate` | `#060911` | грунт, сине-смещённый чёрный |
| `--panel` | `#0B1020` | поверхность карточек |
| `--cold` | `#2BB8FF` | холодный конец температурной рампы |
| `--mid` | `#FF2D8F` | середина рампы |
| `--hot` | `#FF4A1C` | расплав, конец рампы |
| `--silk` | `#16F2AE` | silk-акцент, состояние «успех» |
| `--ink` | `#E9EEFC` | основной текст |
| `--muted` | `#7E8CAC` | вторичный текст |

Фирменный градиент — температурная рампа `cold → mid → hot`. Акцент страницы
задаёт активный пресет и меняет всё сразу: свечение, кнопки, сетку стола,
подсветку внутри корпуса.

## Типографика

- **Nunito** 800/900 — дисплейные заголовки, tracking −2%
- **Nunito Sans** 400/600 — основной текст
- **JetBrains Mono** — данные, цены, состояние принтера (`tabular-nums`)

Все три с кириллицей.

## Эффекты

Курсор-сопло с экструзионным следом, поле частиц с отталкиванием от курсора,
корпус в CSS 3D с наклоном за мышью, стол принтера в перспективе, пробег
печатающей головки при смене цвета, магнитные кнопки, тилт-карточки, появление
секций по скроллу. Всё движение снимается по `prefers-reduced-motion`.

## Что в концепте демонстрационное

ТТХ корпуса, граммовки деталей и цены — заглушки. Их нужно заменить реальными
данными модели ModCase Hyper.
