# MODCASE Hyper

Магазин и конструктор корпуса для ПК, который печатают на 3D-принтере под заказ.
Покупатель собирает набор из шести печатных деталей: выбирает материал и цвет
каждой панели или берёт готовый пресет, видит массу, время печати и цену до оплаты.

Основа — модель [ModCase Hyper Premium Universal PC Case](https://makerworld.com/ru/models/2803591-modcase-hyper-premium-universal-pc-case).

## Стек

Flutter Web (CanvasKit), Riverpod для состояния конструктора, Google Fonts (Nunito, Nunito Sans, JetBrains Mono).

## Структура

```
design/                концепт визуального языка (интерактивная HTML-страница)
lib/src/domain/        детали, филаменты, пресеты, конфигурация и смета
lib/src/theme/         токены (ModColors), типографика, сборка ThemeData
lib/src/state/         Riverpod: активный пресет, конфигурация, смета
lib/src/ui/            страница и виджеты
test/                  расчёт сметы и форматирование
```

Слои разделены так, чтобы формулы сметы (`lib/src/domain/configuration.dart`)
не зависели от Flutter: те же функции переиспользует бэкенд при подтверждении
заказа.

## Дизайн

Визуальный язык описан в [design/README.md](design/README.md): токены,
типографика и список эффектов. Токены живут в `lib/src/theme/` — палитра в коде
и в концепте это один и тот же набор значений.

## Запуск

```bash
flutter run -d chrome
```

Тесты:

```bash
flutter test
```

## Что уже работает

Пресеты переключают тему целиком — акцент интерполируется `AnimatedTheme`,
корпус перекрашивается по деталям. Конструктор считает массу, время печати и
цену на лету. Фон реагирует на курсор: частицы отталкиваются, кнопки
притягиваются, корпус наклоняется.

## Чего ещё нет

Каталог готовых китов, секция материалов, корзина и оформление заказа.
3D-корпус собран на `Matrix4` — под продакшен его место займёт Spline-сцена
или GLB, контракт остаётся прежним: цвета деталей внутрь, наклон снаружи.
Поле частиц стоит перевести на фрагментный шейдер.
